代理启动器 · Windows x64

运行前：Windows 10/11 x64，已安装 .NET 8 Windows Desktop Runtime x64。
现有代理软件已连接，TUN 关闭，本地 SOCKS5 入口支持 TCP 和 UDP。

1. 保持本目录文件完整，以普通方式双击 AuxLauncher.exe。
2. 选择目标 .exe，点击“经代理启动”。
3. 未配置代理入口时会辅助探测；无法唯一确定时，在卡片中填写本地 SOCKS5 地址和端口。该入口保存后长期复用。
4. 接受接管组件的 Windows UAC 授权。目标软件仍使用普通用户权限。
5. 受管程序及子进程全部退出后，启动器自动回收会话。

运行中关窗会隐藏到托盘，不终止目标软件。双击托盘图标重新打开。
最近记录最多四项；鼠标移到历史项可移除，右键当前程序可从记忆中移除。
已保存的代理入口可在空闲时点击标题栏端口修改。

“代理中断”表示受管连接暂停，目标保留，代理恢复后新请求恢复。
“保护中断”表示覆盖曾中断，不能保证期间无直连；即使组件恢复，告警也保留到本会话结束。请自行保存工作后重启目标软件。

设置、加密凭据和日志：%LOCALAPPDATA%\AuxLauncher
日志按组件区分：app.jsonl、guard.jsonl、relay.jsonl。请勿把自己的设置与日志上传到公开仓库。

边界：Windows 共享 DNS 服务查询保持系统原路径；已有实例、服务或共享网络组件代发的流量不自动纳入受管范围。无法归属的数据包按既定原则放行并记日志。首版不支持需管理员权限的目标、IP 分片、广播/多播转发或公网入站服务。
该工具不修改系统全局代理、全局 DNS 或 TUN 设置。

验证记录及完整源码见工程 README.md。受控驱动测试通过不代表所有真实软件和代理组合均已验证。
