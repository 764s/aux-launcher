状态码 对应逻辑阶段 目标文件槽 & 最近行 主操作按钮 底部状态反馈条
IDLE 空闲（无记录或未选） 虚线可点 / 拖入 .exe；按钮「选择」；无其他历史时隐藏最近行 禁用 · 「经代理启动」 隐藏（不占位）
READY 就绪（含自动恢复） 文件名 + 单行等宽路径；按钮「更换」；有其他历史时显示最近芯片行 主色可点 · 「经代理启动」 隐藏（不占位）
MISSING 已记忆路径失效 红框 + 「文件缺失」徽章；按钮「重新定位」；仍可点最近芯片切换 禁用 · 「经代理启动」 error：原路径文件已移动或不存在
PREPARING 启动准备中 主槽锁定 + 脉动蓝点；最近行淡化禁用；标题栏入口芯片禁用 浅蓝加载态 · 「正在准备启动…」 info：核验本地代理、请求接管并启动目标程序
RUNNING 代理运行中 主槽锁定 + 绿点；最近行淡化禁用 浅绿运行态 · 「正在代理运行中」 success：程序已启动，流量已通过本地代理接管（非 TUN）
PROXY_LOST 运行期代理中断 主槽锁定 + 琥珀点；最近行淡化禁用 中性等待态 · 「等待代理恢复…」 warn：本地代理连接中断，已阻止直连；恢复后新请求自动续接
PROTECTION_INTERRUPTED 拦截保护异常中断 主槽红框锁定 + 脉动红点；最近行淡化禁用 浅红告警态 · 「保护异常中断」 error：代理保护意外中断，可能无法阻止直连；保留目标软件，尝试恢复并建议重启目标程序（严禁显示“已阻止直连”）
RECOVERING 会话回收中 主槽锁定 + 脉动蓝点；最近行淡化禁用 浅蓝加载态 · 「正在回收会话…」 info：受管进程已全部退出，正在释放本会话资源
FAILED 启动失败 / 已回滚 解锁可更换；最近行恢复可切换 主色可点 · 「重试」 error：按实际阶段显示失败原因（入口不可达时附「修改入口」快捷按钮）
场景 界面表现与行为约定
常态展示 主界面不常驻配置表单；仅在标题栏右侧窗口按钮旁放一枚极低权重微标（如 :10808 或 未配置），空闲态点击可展开/收起内嵌配置卡，运行锁定态禁用点击。
已保存入口 点「经代理启动」直接复用已保存的本地 SOCKS5 入口，不弹出配置卡；若该入口不可达，进入 FAILED 并在反馈条右侧提供「修改入口」快捷操作，不静默切端口。
未配置：唯一探测 首次点「经代理启动」时探测常见回环 SOCKS5 端口；若仅找到唯一可用入口，自动保存并直接继续启动，无需用户干预。
未配置：多候选 / 未找到 / 需认证 原位平滑展开内嵌「本地 SOCKS5 入口」卡片（388px 宽内紧凑排版）：多候选时提供一键点选芯片；未找到时提示手填地址与端口；需认证时自动展开用户名/密码输入框。点击「保存并启动」后保存复用并自动接续启动。
规范项 精确交互与展示定义
默认恢复 再次打开启动器时自动将上次选定的 .exe 填入主槽并进入 READY，不自动启动。
最近芯片行显隐 仅展示除当前程序外的其他历史项（最多记忆 4 项、芯片行最多展示 3 枚）；无其他历史时整行折叠隐藏。
一键切换与移除 点芯片即切换，点右侧 × 移除该条记忆；移除当前项时清空选择进入 IDLE，不自动改选。
路径失效 文件移动或删除时进入 MISSING 态并保留记录，按钮改为「重新定位」，仍可点最近行切到其他有效程序。
