## 驱动集成测试的准确范围

自动化测试使用自建 SOCKS5 服务、回显服务及目标程序，真实加载已签名 WinDivert。为避免本机既有外网转发组件把测试请求变成其他进程的流量，自测模式对专用回环目标启用拦截：IPv4 使用 `127.0.0.2`，IPv6 使用 `::1`。正式启动器不会启用这个例外。

IPv4 DNS 使用测试目标的 UDP 53 端口。IPv6 DNS 使用受控解析器的动态端口，避开本机对 53 端口的处理；验证了 DNS 内容、地址族和 SOCKS5 路径，**未据此宣称当前环境下 IPv6 UDP 53 已通过**。两者都要求代理侧数据报计数增加，返回测试解析器特有的 `203.0.113.8` 响应。

这些测试证明受控环境中的真实驱动、进程隔离、转发和生命周期链路；不等于普通网卡外网路径、任意代理产品、任意目标软件都兼容。

## 当前真实外网验证的阻塞

在 TUN 关闭的外网路径测试中，捕获到了测试目标请求对应的外发 SYN，但端点归属为会话 Job 外的共享网络进程；测试 SOCKS5 的连接计数没有增加，TCP 转发请求节点未到达。

该轮测试表明连接在捕获点已由共享网络组件代发，不能记作本应用代理成功，也不能据此推断所有软件都不可用。按照会话隔离要求，没有把共享进程加入受管范围，也没有修改其他网络组件。

因此仍需在真实使用环境中按 [README 的实测步骤](../../README.md#真实软件实测)验证至少一款实际目标软件的关键业务，并在另一种主流代理软件入口上复测。共享 DNS 若阻塞实际业务，需继续专项实现与验证；首版没有全局劫持 DNS。
